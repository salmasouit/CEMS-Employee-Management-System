# CEMS – Canal Employee Management System

CEMS is a full-stack web application designed to centralize employee management and HR-related processes within an organization.

The application was developed during my engineering internship at Canal Informatique.

## Features

- Employee and department management
- Leave request and tracking
- User roles and permissions
- Notifications
- Activity logging and audit tracking
- Dashboard
- Secure authentication

## User Roles

- Employee
- HR Manager
- Administrator

## Technologies

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Security
- JWT Authentication
- Password Hashing
- Role-Based Access Control (RBAC)

### Tools
- Git
- GitHub

## Architecture

CEMS follows a Client-Server architecture.  
The React frontend communicates with the Node.js/Express backend through a REST API, while MongoDB is used for data persistence.

## Project Context

This project allowed me to work on requirements analysis, UML modeling, database design, REST API development, authentication and authorization, as well as the development of a complete full-stack application.
